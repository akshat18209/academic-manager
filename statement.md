# Problem Statement

Manually maintaining student marks, calculating percentages and grades, and
compiling report cards is a repetitive and error-prone process for
teachers, especially as class sizes grow. There is a need for a simple,
reliable tool that can manage student records, automate result
calculation, and provide meaningful academic performance insights without
relying on complex database systems or external file formats.

## Scope of the Project

This project delivers a command-line Student Result Management System that:

- Stores and manages student records (roll number, name, subject-wise marks)
- Calculates percentage, letter grade, and pass/fail status automatically
- Generates individual report cards (on-screen and saved as `.txt` files)
- Produces class-wide analytics: average percentage, topper, pass
  percentage, and subject-wise averages
- Persists all data between runs using a plain Python file as storage
  (no database, JSON, or CSV required)

The project is scoped for a single class/section at a time and is intended
to be run and used from the command line.

## Target Users

- **Teachers / Class Administrators** — the primary users, who add
  students, enter marks, and generate reports and analytics
- **Students** (indirectly) — as the subjects of the records, whose
  report cards are generated by the system

## High-Level Features

1. **Student & Subject Management** — add, view, and delete student
   records; add new subjects
2. **Marks Entry & Grade Calculation** — enter/update marks per subject
   with validation; automatic percentage, grade, and pass/fail calculation
3. **Report Card Generation** — formatted report card per student,
   displayed on-screen and saved to a file
4. **Class Analytics** — class average, topper, pass percentage, and
   subject-wise performance breakdown
